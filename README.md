# Bank-Marketing-Analytics-ML
A Predictive Analytics project using Python to predict term deposit subscriptions through data preprocessing, exploratory data analysis, five ML classification algorithms, model evaluation and data visualization.

## Project Overview

Can machine learning predict whether a customer will subscribe to a bank's term deposit?

This project focuses on developing a predictive analytics solution using the Bank Marketing dataset. It applies data preprocessing, exploratory data analysis, statistical analysis and multiple machine learning classification algorithms to predict customer subscription behaviour.

## Objectives

* Explore and understand banking customer data.
* Perform data cleaning and handle missing values.
* Analyse numerical and categorical variables.
* Apply encoding and feature scaling techniques.
* Build and compare five machine learning classification models.
* Evaluate model performance using multiple evaluation metrics.
* Visualize customer behaviour and model performance.

## Technologies Used

* Python
* Pandas and NumPy
* Matplotlib and Seaborn
* Scikit-learn
* Python IDLE

## Machine Learning Algorithms

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Gaussian Naive Bayes
4. Decision Tree Classifier
5. Linear Support Vector Machine (SVM)

## Model Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1-Score
* ROC-AUC
* Confusion Matrix

## Visualizations

The project includes multiple visualizations, including:

* Target variable distribution
* Numerical feature distributions
* Categorical feature analysis
* Correlation heatmap
* Box plots
* Model performance comparison
* ROC curve comparison
* Confusion matrices

## Key Findings

Linear SVM achieved the highest ROC-AUC score of 0.712, closely followed by Logistic Regression at 0.711, while KNN recorded the highest accuracy of approximately 86%. The analysis demonstrates why multiple evaluation metrics are essential for selecting a reliable classification model.

## Dataset Source

Bank Marketing Dataset – UCI Machine Learning Repository.

## How to Run

1. Clone or download this repository.
2. Install the required Python libraries using `pip install -r requirements.txt`.
3. Open the Python file in Python IDLE.
4. Update the dataset path if required.
5. Run the project and explore the generated results and visualizations.

## Conclusion

This project demonstrates the practical application of predictive analytics and supervised machine learning in understanding customer behaviour and predicting term deposit subscriptions through comparative model evaluation.
